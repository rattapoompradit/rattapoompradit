# Clinic Sign

โปรแกรม kiosk สำหรับจอทัชสกรีนแนวตั้งบน Windows — เลือกโลโก้คลินิก แล้วเซ็นชื่อบนจอ

- หน้าแรก: ช่องค้นหาด้านบน + โลโก้คลินิก (รองรับ 100–200 อันขึ้นไป เลื่อนขึ้นลงได้)
- กดโลโก้ → แสดงโลโก้ใหญ่ + กรอบเซ็นชื่อ
- ปุ่ม **ลบ** = ล้างลายเซ็นเพื่อเซ็นใหม่ · ปุ่ม **กลับ** = ล้างแล้วกลับหน้าแรก
- **ไม่บันทึกอะไรเลย** ลายเซ็นอยู่บนจออย่างเดียว ไม่มีการเขียนไฟล์ ไม่ใช้อินเทอร์เน็ต
- ไม่มีใครแตะจอ → ล้างทุกอย่างแล้วกลับหน้าแรกเอง: หน้าแรก 60 วินาที, หน้าเซ็น 5 นาที (เผื่อเวลาถ่ายรูป)
- คีย์บอร์ดไทย/อังกฤษบนจอในตัว (ค้นหาไม่สนตัวพิมพ์เล็กใหญ่ ช่องว่าง และวรรณยุกต์)

## ติดตั้ง

1. ดาวน์โหลด `ClinicSign-Setup.exe` จาก GitHub → Releases → **clinic-sign-latest**
   (หรือ Actions → Clinic Sign EXE → Artifacts)
2. ดับเบิลคลิกติดตั้ง — ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
   (ไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล)
3. โปรแกรมเปิดเต็มจอ และ **ตั้งให้เปิดเองทุกครั้งที่เปิดเครื่อง** (ปิดได้ที่ Task Manager → Startup apps)

## ใส่โลโก้คลินิก

ใส่ไฟล์รูปในโฟลเดอร์ **`Documents\ClinicLogos`** (โปรแกรมสร้างให้ตอนเปิดครั้งแรก)

| กติกา | ตัวอย่าง |
|---|---|
| ชื่อไฟล์ = ชื่อคลินิกที่ใช้ค้นหา (บนจอแสดงแค่โลโก้) | `คลินิกหมอฟัน.png` |
| ใส่ตัวเลขนำหน้าเพื่อกำหนดลำดับ (ตัวเลขไม่แสดงบนจอ) | `001 คลินิกหมอฟัน.png`, `002 Smile Dental.jpg` |
| ไม่มีตัวเลข → เรียงตามตัวอักษร ไว้หลังไฟล์ที่มีตัวเลข | |
| ชนิดไฟล์: png, jpg, jpeg, webp, svg, gif, bmp | |
| ขนาดแนะนำ: ด้านยาวไม่เกิน ~800 px (200 รูปใหญ่ ๆ จะเปลืองหน่วยความจำ) | |

ไฟล์ที่ชื่อขึ้นต้นด้วย `_` จะไม่ถูกนับเป็นโลโก้

### รูปแบบโปสเตอร์ REVIVE (แนะนำ)

ใส่ภาพโปสเตอร์ของแต่ละคลินิกขนาด **1080×1920** (หรือ 2160×3840) ตามเทมเพลต REVIVE ได้เลย:
- **หน้าแรก** — โปรแกรมตัดเฉพาะ **วงกลมขาว** (โลโก้คลินิก) มาเป็นปุ่ม
- **หน้าเซ็น** — แสดงโปสเตอร์เต็มจอ เซ็นด้วยหมึกขาวบนโปสเตอร์ได้เลย (ไม่มีกรอบ) ใต้คำว่า **SKIN READY.**
  ปุ่มไอคอนเล็ก ๆ โปร่งแสงกลางล่าง (🗑 ลบ · 🏠 กลับ) จางจนแทบมองไม่เห็นหลังไม่มีใครแตะ 3 วินาที (แตะจอแล้วกลับมา) เพื่อให้ถ่ายรูปไม่ติด
- ตำแหน่งวงกลมต้องตรงกับเทมเพลตเดิม (กึ่งกลาง x=540, y≈688, เส้นผ่านศูนย์กลาง ≈636 px บนภาพ 1080×1920) และพื้นที่ใต้ y≈1290 ต้องว่างไว้สำหรับเซ็น
- ภาพที่ไม่ใช่แนวตั้ง 9:16 จะถือเป็นโลโก้ธรรมดา (แสดงทั้งภาพ)

### วิดีโอพื้นหลังเมนู + หน้าพักหน้าจอ (ไม่ใส่ก็ได้)

| ไฟล์ในโฟลเดอร์ | ผล |
|---|---|
| `_background.mp4` | วิดีโอวนเป็นพื้นหลังหน้าเมนูคลินิก (มีทั้งรูปและวิดีโอ → ใช้วิดีโอ) |
| `_screensaver.mp4` | เปิดใช้ **หน้าพักหน้าจอ**: เปิดโปรแกรม/ไม่มีใครแตะ (เมนู 60 วิ, หน้าเซ็น 5 นาที) → วิดีโอเต็มจอ + "แตะเพื่อเริ่ม"; หน้าเมนูมีปุ่ม 🌙 กลับไปหน้าพักหน้าจอ |

- รองรับ .mp4 (H.264) / .webm — แนะนำ 1080×1920 แนวตั้ง, ไม่ต้องมีเสียง (เล่นแบบปิดเสียง)
- `_screensaver` ใช้รูปนิ่ง (.jpg/.png) แทนวิดีโอก็ได้
- ไม่มีไฟล์ `_screensaver` → ไม่มีหน้าพักหน้าจอ (ไม่มีใครแตะ → กลับหน้าเมนูเหมือนเดิม)

### ภาพพื้นหลัง (ไม่ใส่ก็ได้)

ใส่ไฟล์ชื่อ **`_background.jpg`** (หรือ .png / .webp) ในโฟลเดอร์เดียวกัน → ใช้เป็นพื้นหลังทั้งหน้าแรกและหน้าเซ็น
- ขนาดแนะนำ 1080×1920 (Full HD แนวตั้ง) หรือ 2160×3840 (4K แนวตั้ง) — รูปจะถูกขยายให้เต็มจอ ส่วนที่เกินจะถูกตัดขอบ
- กล่องโลโก้ กรอบเซ็น และป้ายข้อความเป็นพื้นขาว จึงอ่านออกได้บนทุกพื้นหลัง
- ลบไฟล์ออก = กลับเป็นพื้นสีเดิม

เพิ่ม/ลบ/เปลี่ยนไฟล์ (รวมถึงพื้นหลัง) ระหว่างโปรแกรมเปิดอยู่ได้ หน้าจออัปเดตเองภายใน 1 วินาที

## ออกจากโปรแกรม (สำหรับผู้ดูแล)

- **กดค้างมุมซ้ายบนของจอ 5 วินาที** หรือ
- ต่อคีย์บอร์ดแล้วกด **Ctrl + Shift + Q**

## ตั้งค่า Windows + จอ LG แนวตั้ง (ทำครั้งเดียว)

1. **หมุนจอ:** Settings → System → Display → Display orientation → **Portrait**
   รองรับทั้ง Full HD (1080×1920) และ 4K (2160×3840) — โปรแกรมขยายเองให้พอดีจอ ตั้ง Scale ของ Windows เท่าไรก็ได้
2. **ตั้งทัชให้ตรงหลังหมุนจอ** (สำคัญ — ถ้าข้ามขั้นนี้ แตะแล้วจะไม่ตรงจุด):
   Control Panel → **Tablet PC Settings** → Setup… → เลือก **Touch input** แล้วแตะจอที่มีข้อความขึ้น
   ถ้ายังเพี้ยน กด Calibrate… ในหน้าเดียวกัน
3. **ปิดการปัดขอบจอ** (กันผู้ใช้ปัดออกจากโปรแกรม):
   - Windows 11: Settings → Bluetooth & devices → Touch → ปิด *Three- and four-finger touch gestures*
   - Windows Pro: `gpedit.msc` → Computer Configuration → Administrative Templates → Windows Components → Edge UI → **Allow edge swipe = Disabled**
4. **ไม่ให้จอดับ/เครื่องหลับ:** Settings → System → Power → Screen / Sleep = **Never**
   (โปรแกรมกันจอดับขณะเปิดอยู่แล้ว แต่ตั้งไว้ด้วยจะชัวร์กว่า)
5. **ล็อกอินอัตโนมัติ** เพื่อให้เปิดเครื่องแล้วเข้าโปรแกรมเลย: กด Win+R → `netplwiz`
6. **ทีวี LG:** ปิด *Auto Power Off* / *No Signal Power Off* / *Eco* ในเมนูทีวี และตั้ง Picture mode ให้อ่านง่าย

## ตัวเลือกบรรทัดคำสั่ง

| ตัวเลือก | ผล |
|---|---|
| `--windowed` | เปิดเป็นหน้าต่างปกติ (ไม่เต็มจอ ไม่ตั้ง autostart) ใช้ทดสอบ |
| `--logos=D:\path` | ใช้โฟลเดอร์โลโก้อื่นแทน `Documents\ClinicLogos` |
| `--size=1080x1920` | ขนาดหน้าต่างตอน `--windowed` |
| `--selftest` | ทดสอบอัตโนมัติ (แตะ ค้นหา เซ็น ลบ กลับ) แล้วเขียนผลลง `selftest.txt` |

## สำหรับนักพัฒนา

```bash
npm install
npm start          # เปิดแบบหน้าต่าง ใช้โลโก้ตัวอย่างใน test/fixtures
npm test           # unit test (ชื่อไฟล์, การเรียง, การค้นหา, คีย์บอร์ด)
npm run selftest   # E2E กับ Electron จริง
npm run dist       # สร้าง dist/ClinicSign-Setup.exe (รันบน Windows)
```

โครงสร้าง: `main.js` (หน้าต่าง kiosk, อ่านโฟลเดอร์โลโก้) · `preload.js` · `web/` (หน้าจอ: `app.js`, `keyboard.js`, `logic.js`, `style.css`) · `selftest.js`
ทุก push ที่แก้ `clinic-sign/` บน branch นี้ GitHub Actions จะ build + selftest บน Windows แล้วอัปโหลดไฟล์ติดตั้งให้
