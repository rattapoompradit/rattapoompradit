# Clinic Sign — บันทึกส่งต่อสำหรับ Claude

โปรแกรม kiosk (Electron) บน Windows สำหรับจอทัช LG แนวตั้ง: เลือกคลินิก → เซ็นชื่อบนโปสเตอร์ → คนถ่ายรูปกับจอ
**ออฟไลน์ทั้งหมด และไม่บันทึกลายเซ็นเลย** (ตั้งใจ) — ใช้งานจริงที่อีเวนต์ REVIVE SKIN EXPERT

## วิธีทำงานกับผู้ใช้
- ตอบภาษาไทย กระชับ; ผู้ใช้เน้นประหยัด token → ตรวจให้ครบแล้วทำให้จบในรอบเดียว ถามเฉพาะ blocker/ตัวเลือกที่เปลี่ยนผลลัพธ์
- งานด้านหน้าตา: ถ้าผู้ใช้ขอ "ดูตัวอย่างก่อน" ให้ทำภาพ mockup ให้เลือกก่อนแก้จริง
- ทุกครั้งที่แก้: `npm test` + `npm run selftest` (และลอง `--size=2160x3840` / `--size=540x960`) แล้วดูภาพหน้าจอจริงก่อนส่ง
- **repo นี้เป็น public** — ห้าม commit วิดีโอ/โปสเตอร์/ทรัพย์สินแบรนด์ (`media/*.mp4` ถูก gitignore ไว้แล้ว)

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `main.js` | หน้าต่าง kiosk, อ่านโฟลเดอร์โลโก้ + เฝ้าดูการเปลี่ยนแปลง (fs.watch), zoom ให้ด้านสั้น = 1080px (4K ดูเหมือน FHD), media ที่แถมมากับตัวติดตั้ง |
| `preload.js` | `window.kiosk` = listLogos / onLogosChanged / quit |
| `web/app.js` | 3 หน้า: screensaver → menu (home) → sign, ค้นหา, แผ่นเซ็น (canvas), idle/quiet timers |
| `web/keyboard.js` | คีย์บอร์ดไทย (เกษมณี) / อังกฤษบนจอ |
| `web/logic.js` | ฟังก์ชันล้วน (ใช้ทั้ง Node และหน้าเว็บ): parseLogoFile, specialFile, sortLogos, matches |
| `web/style.css` | หน้าตาทั้งหมด (ค่าตำแหน่งวงกลมโปสเตอร์อยู่ที่นี่) |
| `selftest.js` | E2E ด้วย input event จริง: `--selftest --logos=... [--size=WxH] [--shots=DIR] [--no-bundled-media]` → `selftest.txt` |
| `test/logic.test.js` | unit test (`node --test`) |
| `test/fixtures/` | โลโก้/โปสเตอร์/วิดีโอตัวอย่างขนาดเล็ก (สังเคราะห์ขึ้นเอง) |
| `media/` | วิดีโอที่รวมเข้าตัวติดตั้ง (`_background.mp4`, `_screensaver.mp4`) — **ไม่ commit** |
| `../.github/workflows/clinic-sign-exe.yml` | push branch นี้ → build NSIS บน windows-latest + selftest → release `clinic-sign-latest` (ไม่มีวิดีโอ เพราะไม่อยู่ใน git) |

## พฤติกรรมที่ตกลงกับผู้ใช้แล้ว
- **โฟลเดอร์ข้อมูล:** `Documents\ClinicLogos` (เปลี่ยนด้วย `--logos=PATH`) — เพิ่ม/ลบ/ทับไฟล์ระหว่างเปิดโปรแกรม จออัปเดตเองใน ~1 วิ
  - ชื่อไฟล์ = ชื่อคลินิก (ใช้ค้นหา ไม่แสดงบนจอ), เลขนำหน้า `001 ชื่อ.png` = ลำดับ, ไฟล์ขึ้นต้น `_` ไม่ใช่คลินิก
  - `_background.(mp4|webm|jpg|png…)` = พื้นหลังหน้าเมนู, `_screensaver.(mp4|…)` = หน้าพักหน้าจอ (วิดีโอชนะรูป; ไฟล์ในโฟลเดอร์ชนะ `media/`)
- **โปสเตอร์ (ภาพ 9:16, เทมเพลต REVIVE 1080×1920):** เมนูตัดเฉพาะวงกลมขาว (ศูนย์กลาง 540,687.5 เส้นผ่าน 636 → crop 632) เป็นปุ่ม; หน้าเซ็นแสดงโปสเตอร์เต็มจอ
  เซ็นได้เต็มกว้างใต้คำว่า SKIN READY. (เริ่ม 67vh) ด้วยหมึกขาว ไม่มีกรอบ; ข้อความ/เส้นนำหายเมื่อเริ่มเซ็น
  ภาพที่ไม่ใช่ 9:16 = โลโก้ธรรมดา (เลย์เอาต์เดิม: โลโก้บน + กรอบเซ็นขาว + ปุ่มข้อความ)
- **ปุ่มหน้าเซ็น (โปสเตอร์):** ไอคอนแบบ B — 🗑 ลบ / 🏠 กลับ, วงกลม 2.6rem กลางล่าง, opacity .6 → .12 หลังไม่แตะ 3 วิ (คนถ่ายรูปไม่ให้ติด);
  กดปุ่มระหว่างกำลังลากเส้นจะไม่ทำงาน (กันฝ่ามือ)
- **หน้าเมนู:** ช่องค้นหา + ปุ่ม 🌙 (ไปหน้าพักหน้าจอ, แสดงเมื่อมี screensaver), ปุ่มวงกลมคลินิกไม่มีกรอบขาว/ชื่อ/จำนวน
- **หน้าพักหน้าจอ:** เริ่มโปรแกรมที่นี่ถ้ามีไฟล์, แตะ → เมนู, ป้าย "แตะเพื่อเริ่ม"
- **Idle:** เมนู 60 วิ, หน้าเซ็น 5 นาที (เผื่อถ่ายรูป) → กลับหน้าพักหน้าจอ (ถ้าไม่มี → เมนู); เล่นเฉพาะวิดีโอของหน้าที่เห็น
- **Kiosk:** เต็มจอ, เปิดเองตอนบูต (packaged), กันจอดับ, single instance, ออก = กดค้างมุมซ้ายบน 5 วิ หรือ Ctrl+Shift+Q

## วิดีโอ (ทำด้วย ffmpeg)
- `_background.mp4` = คลิปผ้า 304×540 → อัปสเกล 1080×1920 (deband, hqdn3d, lanczos, unsharp, grain) + ครอสเฟดท้าย→ต้น 1 วิให้วนเนียน, ไม่มีเสียง
  ⚠️ ที่มาคือ Klickpin/Pinterest — ผู้ใช้ต้องเช็กสิทธิ์ใช้งานเชิงพาณิชย์
- `_screensaver.mp4` = "REVIVE_Brand_Reveal_30s" ของทีมผู้ใช้ → ตัดช่วง 10–30 วิ (โลโก้ขึ้นครบแล้ว), ครอสเฟด 2 วิ = ลูป 18 วิ, deband + grain, ไม่มีเสียง
- สูตรลูปเนียน: `[v]trim=start=D:end=L[main]; [v]trim=end=D[head]; [main][head]xfade=fade:duration=D:offset=L-2D`

## เรื่องที่ค้าง
- ยังไม่ได้ทดสอบบนจอ LG จริง (calibrate ทัชหลังหมุนจอ, ความแม่นของปากกา/กรอบ IR, ความลื่นของวิดีโอบนเครื่องจริง)
- LG CreateBoard บางรุ่นสเปกระบุว่าไม่รองรับแนวตั้ง — ให้ผู้ใช้เช็กรุ่นจริง
- รวมวิดีโอในตัวติดตั้ง: ทำบนเครื่อง local ด้วย `npm run dist` (ใส่วิดีโอใน `media/` ก่อน) — CI บน GitHub จะไม่มีวิดีโอ
